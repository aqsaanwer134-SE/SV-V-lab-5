# Complete Operation Schema

| ID | Operation | Pre-condition | Input | Post-condition |
|----|-----------|---------------|-------|----------------|
| OP_01 | performSelfCheck | The chamber has just been powered on. | Status signals from sensors and control devices | All essential sensors are tested. selfCheckPassed is true only if every essential sensor works. If not, the chamber cannot enter normal conservation and the fault is reported. |
| OP_02 | startMonitoring | selfCheckPassed is true. | None | Continuous sampling of temperature, humidity, light, vibration, door and power has started (MONITORING mode). |
| OP_03 | registerArtifact | Monitoring is running and no artifact is currently registered. | artifactID, description, limits (temperature range, humidity range, light limit, vibration threshold, recovery period, stabilization period) | Artifact record and limits are stored and profileLoaded is true. Registration is rejected if limits are missing or invalid (min greater than max). |
| OP_04 | startConservation | Monitoring is running, artifact is registered, profileLoaded is true and door is CLOSED. | doorStatus, profileLoaded | The normal conservation loop is active (CONSERVATION_ACTIVE). If the door is open, monitoring continues but conservation does not start. |
| OP_05 | compareWithLimits | Conservation is active and current readings are available. | Current temperature and humidity, active profile limits | Each parameter is marked WITHIN or OUTSIDE its allowed range and the out-of-range ones are listed. |
| OP_06 | correctEnvironment | Conservation is active and temperature or humidity is outside its range. | Parameter name, current value, target range | Correction command is sent and the recovery timer starts. The parameter is not yet treated as safe. |
| OP_07 | verifyCorrection | A correction command has been sent and the recovery timer is running. | Latest sensor reading, permitted range, recovery period, elapsed time | If the reading is back in range, the condition is marked recovered and the timer stops. If the recovery period ends without recovery, recoveryFailed is true. |
| OP_08 | activateProtection | recoveryFailed is true. | Failed parameter, reason | PROTECTION_MODE is active, normal conservation is stopped, light exposure is reduced and additional environmental controls are turned on. |
| OP_09 | raiseOperatorAlert | A protection, vibration or power event has occurred. | Alert type, artifactID, current readings, timestamp | The alert is delivered to the operator and an alertID is generated. If delivery fails, it is retried and logged. |
| OP_10 | suspendForVibration | An artifact is inside and vibration is at or above the significant threshold. | Vibration reading, vibration threshold | VIBRATION_RESPONSE is active and risky activities (aggressive control actions, door release, handling) are suspended. |
| OP_11 | verifyVibrationStabilization | VIBRATION_RESPONSE is active. | Vibration readings over time, threshold, stabilization period | resumeAllowed is true only if vibration stayed below the threshold for the full period. The timer restarts if vibration rises again. |
| OP_12 | suspendOnDoorOpen | Conservation is active and the door status changes to OPEN. | doorStatus | Normal environmental operation stops immediately and the door-open event is logged. |
| OP_13 | verifyBeforeResume | The door is CLOSED after being open, or vibration has stabilized. | Sensor status, current readings, active limits | If all sensors work and conditions are within limits, resumeAllowed is true and conservation restarts. Otherwise it does not resume and the correction or protection path is followed. |
| OP_14 | handlePowerLoss | Main power is lost during conservation. | Power status, emergency power availability, last known readings | With emergency power, the chamber keeps running on it and the operator is alerted. Without it, the incident is recorded and the chamber enters the safe shutdown state. |
| OP_15 | removeArtifact | The operator has requested removal, the chamber is safe and no protection response is active. | operatorID, artifactID, chamber state | The artifact is released, its record and profile are cleared and the removal is logged with operatorID. If the chamber is unsafe or protection is active, the request is denied with a reason. |
